# Service catalog and SLA

Use when defining what the security team offers and the response commitments.

| File | Use |
|---|---|
| service-catalog.md | Service catalogue template with example SLA tiers |
| service-catalog.csv | 20 fictional items for import into a service management tool |
| sla-tiers.csv | SLA tiers with first response and resolution targets |

Severity alignment (P0 to P3) is defined in [../incident-response/classification-and-severity](../incident-response/classification-and-severity).
