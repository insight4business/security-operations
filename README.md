# Security Operations

Security operations templates organised by sub-process, so you can start from the part of the process you are in. Generic and fictional (Contoso Ltd.); built from real delivery experience.

| Sub-process | Folder | What it contains |
|---|---|---|
| Respond to an incident | [incident-response/](./incident-response) | Playbooks by attack vector, severity matrix, investigation and post-incident reports, breach notification letters, NIST 800-61 checklist |
| Manage vulnerabilities | [vulnerability-management/](./vulnerability-management) | Tracker with example SLAs, patch approval procedure, executive report |
| Control identities and access | [identity-and-access/](./identity-and-access) | Quarterly access review (procedure, tracker, evidence) and privileged access (PIM) configuration |
| Define services and SLAs | [service-catalog-and-sla/](./service-catalog-and-sla) | Service catalogue template, SLA tiers, 20 fictional items |

## How to use

1. Copy the template you need.
2. Replace every `<PLACEHOLDER>` with your own values.
3. Review with your own legal and security teams before adopting.
