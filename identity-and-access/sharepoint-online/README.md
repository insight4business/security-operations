# Sharepoint Online

Scripts for the **sharepoint-online** technology in this sub-process.

## Scripts adapted from field work

Each script solves one problem. They were adapted from real operations work: replace every `ENTRE_AQUI_COM_SEU_*` marker, review, and test in a non-production tenant first.

| Script | Problem it solves | What it does | Requires | Effect | Notes |
|---|---|---|---|---|---|
| `add-site-admin-to-listed-sites.ps1` | An admin needs access to a defined set of sites. | Loops a list of site URLs and adds the user as site collection admin. | SPO Management Shell; SharePoint Administrator | changes-state | Variable $sitesToAdd; URL list placeholders. |
| `add-site-collection-admin-to-all-sites.ps1` | We need one admin account with access to every site (audit or migration). | Adds a user as site collection admin on all non-read-only sites with a report. | SPO Management Shell; SharePoint Administrator | changes-state | Grants broad access: log and remove afterwards with the removal script. |
| `add-site-owner-to-all-sites.ps1` | We need one user to be owner of every site. | Adds a user to the Owners group of all non-read-only sites with a report. | SPO Management Shell; SharePoint Administrator | changes-state | Broad access grant; find group by login name wildcard '*Owners*'. |
| `create-list-only-permission-level-on-folder.ps1` | Users should see file names in a folder but not open them. | Creates a custom permission level (view items, browse directories) and applies it to a folder for a user or group. | PnP.PowerShell; Site Owner/Admin | changes-state | Portuguese; stray Install-Module and a connection to the tenant root before the real connection; placeholders 'seudominio', 'grupo@example.com', list 'Tests'. |
| `enforce-library-folder-permissions-by-group.ps1` | Folder permissions in a document library drift from the intended group-based model. | Walks a library folder tree, grants a role to a group and removes other direct permissions (controlled by a $readOnly switch). | PnP.PowerShell 1.12; AzureAD module; SharePoint admin | destructive | Client-specific folder names ('Application - Online','Credit') and group name comment; AzureAD module retired; large script with placeholder nuget version; test with $readOnly=$true first. |
| `remove-site-admin-from-listed-sites.ps1` | A user must be removed as admin from a defined set of sites. | Loops a list of site URLs and removes the user as site collection admin. | SPO Management Shell; SharePoint Administrator | destructive | Variable $sitesToAdd reused in the remove script (misleading name); URL list of placeholders. |
| `remove-site-collection-admin-from-all-sites.ps1` | A temporary or former admin is still site collection admin on many sites. | Loops all non-read-only sites and removes the user as site collection admin, building a result report. | SPO Management Shell; SharePoint Administrator | destructive | Report variable inconsistent in sibling scripts (typo $siteAdmin in the owner variant). |
| `remove-site-owner-from-all-sites.ps1` | A former owner still sits in the Owners group of many sites. | Removes the user from the Owners group of all non-read-only sites with a report. | SPO Management Shell; SharePoint Administrator | destructive | Report uses undefined variable $siteAdmin (bug) instead of $siteAdminUPN. |
| `report-file-and-folder-permissions-all-sites.ps1` | We cannot tell who has unique permissions on files and folders across the tenant. | Iterates all sites, libraries and folders/files and exports unique permissions to Excel/CSV. | PnP.PowerShell; ImportExcel; SharePoint Administrator | read-only | Very slow at tenant scale; output to C:\Temp\SharePoint Export. |
| `report-file-and-folder-permissions-per-site.ps1` | We cannot tell who has unique permissions on files and folders in a given site. | Walks one site's lists, folders and items and exports unique permissions to CSV. | PnP.PowerShell; ImportExcel; Site Owner/Admin | read-only | Report path C:\Temp\SitePermissionRpt.csv hard-coded; Portuguese comment; slow on large sites. |
| `report-permissions-all-sharepoint-sites.ps1` | We cannot tell who has access to which SharePoint sites. | Temporarily adds the admin as site owner, collects users, groups and permission levels per site (expanding M365 groups through Graph), then exports to Excel and removes the admin. | PnP.PowerShell; Microsoft.Graph (Group.Read.All); ImportExcel; SharePoint Administrator | changes-state | Not purely read-only: it temporarily changes site ownership (Set-PnPTenantSite -Owners). Based on NovaPoint sample. Admin UPN placeholder. |
