# Exchange Online

Scripts for the **exchange-online** technology in this sub-process.

## Scripts adapted from field work

Each script solves one problem. They were adapted from real operations work: replace every `ENTRE_AQUI_COM_SEU_*` marker, review, and test in a non-production tenant first.

| Script | Problem it solves | What it does | Requires | Effect | Notes |
|---|---|---|---|---|---|
| `create-exchange-service-principal-with-role.ps1` | An application needs Exchange Online rights and we want them least-privilege. | Registers the Entra app as an Exchange service principal and assigns the View-Only Recipients management role. | ExchangeOnlineManagement module; Exchange Administrator; app and object IDs | changes-state | AppId/ObjectId/resource name placeholders; includes unused Get-ServicePrincipal and Get-ManagementRole calls. |
| `export-mailbox-and-group-permissions-and-members.ps1` | We cannot tell who has access to non-user mailboxes or who is in distribution groups. | Exports non-user mailbox permissions and distribution group owners/members into one Excel report. | ExchangeOnlineManagement module; Exchange Administrator; ImportExcel | read-only | Stray $subscriptionId placeholder. |
| `find-orphaned-shared-mailboxes.ps1` | Shared mailboxes exist with no assigned users and no forwarding (orphaned). | Counts permissioned users per shared mailbox and shows those with zero and no forwarding. | ExchangeOnlineManagement module; Exchange Administrator; AzureAD module (retired) | read-only | Uses the retired AzureAD module; calls Get-AzureADUser on the mailbox UPN (may fail for shared mailboxes). |
| `list-exchange-role-group-members.ps1` | We do not know who holds admin roles in Exchange Online. | Lists every Exchange role group, its roles and members and exports to Excel. | ExchangeOnlineManagement module; Exchange Administrator; ImportExcel | read-only |  |
| `remove-disabled-users-from-distribution-groups-by-csv.ps1` | Disabled accounts remain members of mail distribution lists. | Reads a semicolon CSV and removes members from GroupType 'Mail' groups; Remove-DistributionGroupMember is commented out so it only logs. | ExchangeOnlineManagement module; Exchange Administrator | destructive | Same CSV format as the unified-group script; hard-coded dated CSV path. |
| `remove-disabled-users-from-m365-groups-by-csv.ps1` | Disabled accounts remain members/owners of Microsoft 365 groups. | Reads a semicolon CSV (GroupId;GroupName;GroupType;MemberUserPrincipalName) and removes each member (owner first) from Microsoft 365 groups; removal calls partly commented. | ExchangeOnlineManagement module; Exchange Administrator | destructive | Hard-coded CSV path with a dated Portuguese file name; the removal lines are commented out (dry-run by default). |
| `remove-disabled-users-from-shared-mailboxes.ps1` | Disabled accounts still hold Full Access, Send As and Send on Behalf on shared mailboxes. | Finds disabled trustees across shared mailboxes and removes the permissions; removal calls are commented out; designed for managed identity. | ExchangeOnlineManagement module; Exchange Administrator; Microsoft.Graph; managed identity | destructive | Removal lines commented out (dry run). Log path C:\Temp\Logs may be referenced. |
| `remove-send-as-and-send-on-behalf-from-listed-mailboxes.ps1` | Former staff or wrong users can still send as certain mailboxes. | Collects Send As and Send on Behalf for a list of mailboxes and removes them; removal lines commented out (dry run). | ExchangeOnlineManagement module; Exchange Administrator; AzureAD module (retired) | destructive | Long list of placeholder e-mails; uses retired AzureAD module; hard-coded C:\Temp\Logs. |
| `remove-send-on-behalf-from-listed-mailboxes.ps1` | Users keep Send on Behalf rights on mailboxes they no longer need. | Collects Send on Behalf entries for a list of mailboxes and removes them; removal commented out (dry run). | ExchangeOnlineManagement module; Exchange Administrator; AzureAD module (retired) | destructive | Long list of placeholder e-mails; retired AzureAD module. |
| `report-disabled-users-with-shared-mailbox-access.ps1` | Disabled accounts still hold permissions on shared mailboxes. | Lists permissions on shared mailboxes and flags whether each trustee account is enabled. | ExchangeOnlineManagement module; Exchange Administrator; AzureAD module (retired) | read-only | Uses the retired AzureAD module; rewrite with Microsoft Graph. |
| `report-mailbox-permissions-simple.ps1` | We cannot tell who has access to which mailboxes. | Reports Full Access, Send As and Send on Behalf permissions per mailbox with trustee details from Entra ID. | ExchangeOnlineManagement module; Exchange Administrator; AzureAD module (retired) | read-only | Uses the retired AzureAD module; output step not visible in sanitised copy. |
| `restrict-app-mail-access-with-application-access-policy.md` | An app with Graph Mail permissions can reach every mailbox in the tenant. | Runbook (Portuguese) that creates a mail-enabled security group and an Application Access Policy limiting a Managed Identity/app to one mailbox. | ExchangeOnlineManagement module; Exchange Administrator; Exchange Administrator | changes-state | Portuguese text; placeholders for resource and mailbox. |
