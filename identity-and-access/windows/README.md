# Windows

Scripts for the **windows** technology in this sub-process.

## Scripts adapted from field work

Each script solves one problem. They were adapted from real operations work: replace every `ENTRE_AQUI_COM_SEU_*` marker, review, and test in a non-production tenant first.

| Script | Problem it solves | What it does | Requires | Effect | Notes |
|---|---|---|---|---|---|
| `add-local-admin-by-profile-name.ps1` | A specific cloud user needs temporary local admin rights on this device. | Searches Entra ID profiles by name fragment, resolves the SID and adds it to the local Administrators group. | Local administrator | changes-state | Name fragment match may hit several profiles; privilege grant - log and time-box it. |
| `add-user-to-remote-desktop-users.ps1` | A cloud user needs RDP access to a device. | Converts the Object ID to a SID and adds it to Remote Desktop Users. | Local administrator | changes-state | Default param is a placeholder (ENTRE_AQUI_COM_SEU_ID); grants remote access. |
| `clear-deny-interactive-logon-right.ps1` | A baseline denies local accounts interactive logon and I must regain access for troubleshooting. | Exports security policy with secedit, clears SeDenyInteractiveLogonRight and re-applies it. | Local administrator | destructive | Removes a security restriction; troubleshooting/break-glass use only; Intune may re-apply the policy. |
| `convert-entra-object-id-to-sid.ps1` | I have an Entra ID user Object ID and need the matching local SID to grant rights on a device. | Function that converts an Object ID GUID into the S-1-12-1-* SID. | None (pure conversion) | read-only | Placeholder ENTRE_AQUI_COM_SEU_ID must be replaced before the demo call runs; third-party author credit (Oliver Kieselbach) - keep attribution/check licence. |
| `convert-entra-sid-to-object-id.ps1` | I see an S-1-12-1-* SID on a device and need the Entra ID user it belongs to. | Function that converts the SID back into the Object ID GUID. | None (pure conversion) | read-only | Contains a sample SID; third-party author credit (Oliver Kieselbach) - keep attribution/check licence. |
| `detect-primary-user-local-admin.ps1` | I want to know whether the device's primary user already holds local admin. | Finds the primary user via WorkplaceJoin registry data and checks local Administrators membership; exit code for detection. | Local administrator (SYSTEM) | read-only | Unused onboarding Object ID placeholder (ENTRE_AQUI_COM_SEU_ID); membership check compares names to net localgroup output (fragile). |
| `enable-legacy-laps-policy.ps1` | Local admin passwords are identical across devices. | Sets AdmPwdEnabled=1 for legacy Microsoft LAPS. | Local administrator | changes-state | Legacy LAPS (AdmPwd); same 'only if key missing' logic flaw; prefer Windows LAPS policy. |
| `get-device-primary-user.ps1` | I need to know who the primary (Entra-joined) user of this device is. | Reads WorkplaceJoin AADNGC data in user hives and reports the primary user. | Local administrator | read-only |  |
| `get-sid-for-entra-user.ps1` | I need the SID of a cloud user to set local permissions. | Translates an AzureAD\UPN account to a SID. | Local user; device joined to Entra ID | read-only | Placeholder ENTRE_AQUI_COM_SEU_EMAIL@example.com. |
| `grant-local-admin-by-object-id.ps1` | I need to add an Entra ID user to the local Administrators group via Intune/RMM. | Converts the Object ID to a SID and calls Add-LocalGroupMember on the Administrators group. | Local administrator | changes-state | Default param is empty; group name derived with Trim('BUILTIN\') (character trim, locale fragile). |
| `grant-primary-user-local-admin.ps1` | The device owner needs admin rights without handing out a shared account. | Identifies the primary user from the registry and adds them to local Administrators, then removes the onboarding account. | Local administrator (SYSTEM) | changes-state | Placeholder ENTRE_AQUI_COM_SEU_ID for onboarding account removal; privilege escalation by design - tie to an approval. |
| `label-local-user-accounts.ps1` | I cannot tell local accounts from corporate accounts on devices during access review. | Lists local users (RID >= 1000) and renames them with a '(LOCAL) ' prefix. | Local administrator | changes-state | Renaming accounts may break scripts/services that reference the old name; prefix hard-coded. |
| `remove-local-admin-by-profile-name.ps1` | Temporary admin rights must be removed again. | Searches Entra ID profiles by name fragment and removes the account from the local Administrators group. | Local administrator | changes-state | Name fragment match may hit several profiles; example comment mentions an onboarding account name. |
| `revoke-local-admin-by-object-id.ps1` | Admin rights for an Entra ID user must be removed. | Converts the Object ID to a SID and removes it from the local Administrators group. | Local administrator | changes-state | Default param is empty; Trim('BUILTIN\') locale fragility. |
| `revoke-primary-user-local-admin.ps1` | Remove local admin from device owners to enforce least privilege. | Identifies the primary user and removes them from local Administrators. | Local administrator (SYSTEM) | changes-state | Unused onboarding Object ID placeholder; membership test compares names to net localgroup output (may skip removal). |
